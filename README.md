# Brewing Ideaz SEO Plans

## Chosen backlink scope

The best and most realistic scope for this project is: backlinks for the 10 target SEO keyword pages/blogs only.

This is the correct default because the repository is organized around 10 keyword SEO plans, not a full-site SEO campaign. We should only expand to the whole Brewing Ideaz website if the client explicitly asks for homepage, services, portfolio, about, and contact page backlinks.

### Decision

Primary target:
- The 10 SEO keyword pages/blogs in this repository

Secondary only if client confirms:
- Homepage
- Services pages
- Portfolio
- About page
- Contact page
- Full website pages

### Why this is the best option
- Matches the actual project structure
- More targeted and relevant to keyword rankings
- Easier to measure and track
- Lower cost and higher ROI than broad full-site link building
- Keeps the strategy aligned with the SEO plans already prepared

### Client clarification to send

"Just to confirm the backlink scope: should I build backlinks to the 10 target SEO keyword pages/blogs we are optimizing, or to the full Brewing Ideaz website (homepage, services, portfolio, about page, etc.)? I’ll prioritize the 10 keyword pages unless you want full-site link building."

### Recommended execution order
1. Build local citations and Google Business Profile
2. Submit to relevant local directories
3. Reach out for guest post opportunities
4. Build niche mentions and resource links
5. Track all outreach and live links in one spreadsheet
6. Keep anchor text varied: brand, keyword, partial keyword, generic

### Final recommendation
Backlinks should focus on the 10 SEO pages in this repo unless the client clearly instructs otherwise.
